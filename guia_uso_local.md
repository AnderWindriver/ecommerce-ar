# Guía rápida de ejecución local

> Ejecuta los siguientes comandos en tu terminal para levantar el proyecto.

### 1. Clonar el repositorio
```bash
gh repo clone AnderWindriver/ecommerce-ar
cd ecommerce-ar
```

### 2. Instalar dependencias
```bash
npm install
```

### 4.Iniciar api express en una terminal
```bash
node  js/server.js
```

### 3. Iniciar el servidor local en otra terminal aparte
```bash
npm run dev
```

---
🌐 **Dirección de acceso:** Una vez iniciado, abre en tu navegador: `http://localhost:5173/html/index.html` (o `http://localhost:5173/`, que redirige al inicio).
